# Spool

Spool captures, shares, and resumes coding-agent sessions while keeping the original session record authoritative.

## Language

**Summary**:
An optional Markdown overview attached to a shared Hub Session. It may be written by the author or generated by the author’s Local Agent, but it is not part of the original Session transcript.
_Avoid_: Note, message, summary draft

**Local Agent**:
A coding-agent application installed on the user’s machine that runs with the user’s own model, provider, and authentication settings.
_Avoid_: Model, provider
