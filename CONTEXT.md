# Spool

Spool is the publishing platform for agent sessions, starting with coding agents. It turns Sessions into readable, discoverable, and resumable work artifacts while keeping the original Session authoritative. Nothing leaves local preparation until an explicit Share, and nothing enters public Discovery until an explicit Publish.

## Language

**Session**:
The authoritative conversation record produced by a coding agent, including the user and assistant messages and any recorded tool activity.
_Avoid_: Chat, thread, transcript

**Shared Session**:
A Session an author has explicitly shared through Spool so other people can read it and, when supported, resume it as new work. A Shared Session is either Link-only or Public.
_Avoid_: Post, upload

**Share**:
Create a Shared Session and receive a durable URL for it. A new share is Link-only unless the author explicitly publishes it. Sharing does not expose the author’s other Sessions.
_Avoid_: Sync, export

**Publish**:
Make a Shared Session Public so it can appear on the author’s Profile and in Discovery.
_Avoid_: Share, upload, list on profile

**Link-only**:
A Shared Session that is available to people who have its URL but is not listed on the author’s Profile or in Discovery.
_Avoid_: Private, secret

**Public**:
A Shared Session that may appear on the author’s Profile and in Discovery. Public does not imply that unrelated local Sessions are visible.
_Avoid_: Profile-listed

**Profile**:
An author’s public identity and collection of Public Sessions on Spool.
_Avoid_: Account page, library

**Discovery**:
The public surfaces where people browse or search Public Sessions, authors, and topics.
_Avoid_: Feed, marketplace

**Resume**:
Continue from a Shared Session by creating a new Session that preserves the source relationship. The Shared Session is never modified.
_Avoid_: Reopen, restore, merge

**Summary**:
An optional Markdown overview attached to a Shared Session. It may be written by the author or generated by the author’s Local Agent, but it is not part of the original Session.
_Avoid_: Note, message, summary draft

**Local Agent**:
A coding-agent application installed on the user’s machine that runs with the user’s own model, provider, and authentication settings.
_Avoid_: Model, provider
