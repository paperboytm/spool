# Historical release videos

This directory preserves source from past release announcements. The Electron capture skill and
reusable launch template were retired with the Desktop distribution pipeline on 2026-07-23.

Existing versioned compositions remain historical artifacts and are not part of the workspace,
CI, or release train. Any future announcement tooling must begin from the current CLI + Web product
and follow `DESIGN.md`; do not restore the Electron capture pipeline.
